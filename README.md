# 客房管理系统（Room Management System）

面向单家民宿私有部署的客房管理系统：无登录认证、开箱即用，支持全日租、钟点房、长租三种计费方式，支持多门店。

- 当前版本：1.3.9
- 作者：ECHO4502

## 技术栈

- 后端：Python 3.10+ / FastAPI / SQLite（原生 `sqlite3` 驱动，无 ORM）
- 前端：Vue 3 + Element Plus + Vant 4（PC / 移动端自适应，FastAPI 直接托管）
- 打包：PyInstaller 打包为单文件 exe，Windows 系统托盘后台守护

## 获取项目

## 运行环境要求

| 组件 | 版本 | 用途 |
| --- | --- | --- |
| Python | 3.10+ | 运行与打包后端 |
| Node.js + npm（或 pnpm） | 18+ | 构建前端（仅打包或前端开发时需要） |

## 方式一：命令行本地运行

```bash
# 1. 安装后端依赖（专用虚拟环境，避免污染系统 Python）
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# 2. 启动后端
python backend/main.py
```

浏览器访问 <http://127.0.0.1:8000>，API 文档见 <http://127.0.0.1:8000/docs>。
首次启动自动创建数据表、默认设置、1 个示例房间和默认入住渠道。

前端开发模式（可选，仅在修改前端代码时使用）：

```bash
cd frontend
npm install        # 或 pnpm install
npm run dev        # 打开 http://127.0.0.1:5173，/api 自动代理到后端
```

可通过环境变量调整启动参数：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `HOTEL_HOST` | `0.0.0.0` | 监听地址（局域网其他设备可访问） |
| `HOTEL_PORT` | `8000` | 监听端口（被占用时自动顺延） |
| `HOTEL_DB_PATH` | `data/hotel.db` | 数据库文件路径 |

## 方式二：打包为 exe 部署

```bash
# 1. 安装后端依赖（专用虚拟环境）
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# 2. 安装前端依赖并构建生产版本（产物输出到 frontend/dist）
cd frontend
npm install        # 或 pnpm install
npm run build
cd ..

# 3. 打包 exe（务必使用虚拟环境的 Python，系统 Python 未安装 PyInstaller）
.venv\Scripts\python.exe build.py
```

- 交付物：`dist\客房管理系统.exe`（单文件）；将项目根目录的 `使用说明.txt` 复制到 exe 旁边一并交付。
- 数据库不打包：首次运行自动在 exe 同级创建 `data/hotel.db`，升级程序不丢数据。
- 运行 exe 自动打开本机浏览器（http://127.0.0.1:8000）、尝试放行防火墙端口（无管理员权限时静默跳过）、写入 `ip.txt` 并驻留系统托盘。
- `build.py` 会自动确认前端构建产物（`frontend/dist`）；前端离线依赖缺失时会自动下载到 `frontend/vendor/`。

## 业务规则

- 房间：所有房间均为普通房间，以「房号 + 房型」展示（房间名称已弃用）；房型可在系统设置中自定义；编辑页可设置「全日价」与「钟点价」两个价格。
- 房间模板与批量新建：新增房间时可保存房型与价格为模板并快速套用；支持按楼层起止与每层房间数批量生成房号（楼层号 + 房间号）。
- 批量编辑：可按门店 / 房型 / 楼层筛选，批量设置或增减全日价、钟点价。
- 订单自动维护：默认关闭；设置页提供启用开关（开启时风险提示并自动备份，不处理长租订单），启用后可分别开启自动入住 / 自动退房 / 自动续住（退房与续住互斥）；订单详情可对单笔订单独立开启「自动入住」与「到期自动操作」（开启后选择到期执行为自动退房或自动续住，控件单行展示），两个开关互不影响、到点自动执行；自动续住按日单价累加金额（钟点房不超过日租价）且备注累计续住次数；自动维护处理过的订单在房态网格以绿色边框提示；自动操作会写入订单与收支备注并记录日志（设置页可查看，含订单日期/房号/客人并可查看详情），支持全局 / 单笔回滚（回滚后记录移除并关闭对应自动化）。
- 计费方式：`full_day` 全日租（默认入住日 14:00 入住、离店日 12:00 退房，按晚计费）、`hourly` 钟点房（按日租原价计费：至少收一晚日租价，订单时间每超过一个次日 12:00 即多收一晚，上限随超时逐日上调）、`long` 长租（按日计价，支持日结收款、一次性结算或退房结算）。
- 结算方式：日租与钟点房可选择「入住前实收」或「退房到账」，仅直接到账渠道（或未选渠道现金）可选「入住前实收」，其余渠道仅能退房结算；长租支持一次性先付 / 日结 / 退房结算，续住分段按各自结算日计算回款；先付订单创建即计入收支；退房时可按实际收款调整金额并自动标记多收/少收；提前退房/取消时可登记退回金额并从收支扣除。
- 订单状态流转：`已预订 → 已入住 → 已退房`；`已预订 → 已取消`。
- 房态网格（时段化）：订单只占用实际入住时段（全日租占 14:00 至次日 12:00，钟点房按实际时间，长租逐日标注），占用色块内显示客人姓名、来源与价格，颜色按入住渠道区分；已退房订单变灰并以斜线标记；跨天订单不截断，空白时段仍可继续预订。
- 多门店：房态总览下方提供门店分页，可手动新增并命名门店；房间 / 订单 / 收支均按门店隔离。
- 时间轴：24 小时时间轴视图，支持切换日期查看各房间占用与已退房订单。
- 订单管理：可按门店（默认当前门店，可切换全部门店 / 其他门店）、订单类型（日租 / 长租 / 钟点）、入住平台、状态、关键字（订单号 / 客人姓名 / 手机号，回车查询）及日期范围（全部 / 年 / 月 / 日，全部可自选起止日期）筛选；日查询展示涉及该日的全部订单，年 / 月按订单起始日期归属。
- 收支明细：收入与支出（支持新增收支、编辑、删除）、退费、订单关联自动备注（含房号）；门店筛选包含“全部门店”选项，选择后即时刷新；类型筛选为全部 / 收入 / 已回款 / 待回款 / 支出，仅筛选明细，顶部六项统计卡片（总销售额 / 已回款 / 待回款 / 收入笔数 / 总支出 / 净收益）不受其影响；支持关键字（客人 / 手机号 / 房号 / 订单号）查询，按年 / 月 / 日 / 全部（全部可自选起止日期）查看，支持前后翻页、返回上一级与点击日 / 月钻取。
- 入住渠道：设置页可自定义渠道名称与颜色（10+ 种颜色可选），网格按渠道颜色区分。
- 房间管理：启用 / 停用、维修开关、需打扫标记；状态筛选含空闲 / 已预订 / 已入住 / 维修 / 需打扫，另设启用状态筛选；支持按房号 / 房型关键字搜索。
- 日结长租：收款记录与收款操作集成在订单详情内（详情下方直接查看与登记每日收款）。
- 待处理提醒：房态页右上角提供折叠提醒（应入住 / 应退房 / 长租未收款），展开为浮框，点击可定位订单。
- 数据与权限：无登录认证，适合单机 / 局域网私有部署；房间删除为软删除（停用），订单删除为物理删除，不可恢复。

## 数据备份

- 一键备份：设置页「一键备份」通过 sqlite3 备份 API 生成 ZIP 并保存到数据库同级 `backups/` 目录。
- 自动备份：系统每次启动自动备份到数据库同级 `backups/` 目录；备份文件名包含具体时间与原因（启动自动备份 / 自动维护前保留 / 读取备份前保留），仅启动自动备份参与滚动清理（保留最近 7 份），高危操作保留的备份不会被覆盖。
- 读取备份：设置页「一键备份并下载」旁的「读取备份」按钮可查看备份列表（含备份时间与原因）并恢复（恢复前自动保留当前数据）；每条备份旁可删除（删除前二次确认）。
- 备份接口：`GET /api/backup/download`（下载 ZIP）、`GET /api/backups`（备份列表）、`POST /api/backup/restore`（恢复）、`POST /api/backup/delete`（删除备份）、`GET /api/db-info`（房间 / 订单数、版本号、作者）。

## 局域网与手机扫码访问

- 服务默认绑定 `0.0.0.0` 并自动探测局域网 IP（如 192.168.x.x），启动时控制台打印手机访问地址；端口被占用时自动顺延（8000 → 8001 …）。
- 设置页「手机扫码访问」展示二维码（`GET /api/qrcode` 返回 PNG），手机连同一 Wi-Fi 扫码即可打开系统。
- 打包后的 exe 双击运行会自动打开本机浏览器（PC 走 http://127.0.0.1:8000），并驻留系统托盘。

## 旧库迁移

旧版「全日房/钟点房」结构迁移到普通房间结构：

```bash
python migrate_room_type.py
```

服务启动时也会自动执行同样的迁移，无需手动操作。

## API 概览（主要接口）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/db-info` | 系统信息（版本 / 作者 / 房间数 / 订单数） |
| GET | `/api/qrcode` | 局域网访问二维码（PNG） |
| GET | `/api/backup/download` | 一键备份并下载 ZIP |
| GET | `/api/stores` | 门店列表 |
| GET | `/api/rooms` | 房间列表（支持状态、关键字过滤） |
| GET | `/api/available-rooms` | 指定时间段可预订的房间（start_ts/end_ts） |
| POST/PUT/DELETE | `/api/rooms` | 房间增改删（软删除） |
| GET | `/api/orders` | 订单列表（状态、类型、房间、关键字、日期区间过滤） |
| POST | `/api/orders` | 新建订单（价格计算 + 冲突检测） |
| PUT/DELETE | `/api/orders/{id}` | 修改 / 删除订单 |
| POST | `/api/orders/{id}/checkin` | 办理入住 |
| POST | `/api/orders/{id}/checkout` | 办理退房（按实际时长结算、多收/少收标记） |
| POST | `/api/orders/{id}/cancel` | 取消订单 |
| POST | `/api/orders/{id}/extend` | 续住 |
| GET/POST | `/api/orders/{id}/payments` | 长租日结收款记录 |
| GET | `/api/statistics/today` | 今日应到 / 应退 / 总收入 |
| GET | `/api/statistics/revenue` | 收支明细（年 / 月 / 日 / 全部，全部可自选日期范围） |
| GET | `/api/room-status` | 日期范围内房态（时段化占用段） |
| GET/POST/PUT/DELETE | `/api/expenses` | 支出 / 手动收支管理 |
| GET/POST/PUT/DELETE | `/api/channels` | 入住渠道管理 |
